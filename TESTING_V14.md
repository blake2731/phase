# PHASE v14 Tester Reference

## First priority: popup stability

Test ORIGIN, ORIGIN BREAKS, a normal acquisition, ORIGIN HOLDS, and A PATH EXISTS.

Expected:

1. No fully rendered popup flashes before the staged presentation begins.
2. No Continue button flashes briefly and disappears again.
3. The presentation should feel like one continuous card, not two versions swapping places.
4. Holding or mashing Space should still fail to skip a major moment until a fresh acknowledgment is allowed.

## Music research test

### ORIGIN

Expected: a short ascending phrase reaches a clear final arrival.

### ORIGIN BREAKS

Expected: the recognizable phrase returns but stops before its final arrival. It should feel incomplete rather than simply sad or noisy.

### ORIGIN HOLDS

Expected: the phrase returns again, hangs briefly near its expected ending, then finally resolves. The emotional target is recognition plus relief.

## Report at first note

Stop whenever the first thing feels wrong or especially good.

Useful feedback:

1. Did any overlay still visibly swap states?
2. Did the Continue control feel naturally delayed or annoying?
3. Did Origin's music register as the same musical idea across the three moments?
4. Did the broken version feel unfinished?
5. Did the restored version feel satisfying?
6. Was any major moment still drowned out by background audio or UI chatter?
