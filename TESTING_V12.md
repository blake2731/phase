# PHASE v12 Tester Reference

## Research goal

Does a visible unresolved relationship create a question the player remembers and wants to answer?

Play naturally first. Check the Journal only when you genuinely want to.

## Curiosity questions

### The Distant Triangle
Open condition: Pulse acquired and P approaches the unreachable Mode 3 structure.
Expected feeling: I can see it. My Pulse almost reaches it. I want to know how to reach it.
Answer: Resonant Reach lets P reach the note and learn Mode 3.

### One Structure, Two Modes
Open condition: Mode 3 known and P approaches the distant 2/3 Superposition pocket.
Expected feeling: I recognize both symbols, but the geometry keeps them beyond normal reach.
Answer: enough Pulse range lets both learned modes reach the same structure.

### Beyond P's Edge
Open condition: P sees the Fivefold Key beyond the western Field Edge.
Expected feeling: I remember this object even though P cannot reach it.
Answer: restored Phi can cross the edge and retrieve it.

### The Quiet Well
Open condition: P approaches the Echo Well in Echo Reach.
Expected feeling: this structure behaves differently from normal resonators.
Answer: a Pulse returns with the same mode after a delay.

### The Relay Is Not the Source
Open condition: the apparent Source is revealed as a relay.
Expected feeling: if this is repeating a signal, where is the original coming from?
Answer: reaching the larger fivefold Source farther east.

## Visual behavior

Open questions use an incomplete ring around their world target when relevant.
A Pulse that ends just short of Mode 3 or the Superposition target should make that target answer faintly.
Resolved questions briefly close their ring.

## Things to report

1. Which question did you remember without opening the Journal?
2. Which one felt forced or obvious?
3. Did any incomplete ring look like meaningless decoration?
4. Did a near miss make you want more Pulse range?
5. Did resolving an old question feel better than finding a brand new object?
6. Which open question would you remove?
7. Where should PHASE plant an unanswered question earlier?
