# PHASE v15 Tester Reference

Play once without trying to analyze the sound system.

## Opening

1. ORIGIN
Expected: the opening feels like a memory, not a tutorial card.

2. Wake all four lights
Expected: the individual light notes feel like pieces of one familiar ritual.

3. FOUR NOTES
Expected: this extra story beat makes the following rupture matter more without feeling like unnecessary exposition.

4. Return to Origin and trigger the old song
Expected: the player understands this is a repeated home ritual before it breaks.

5. ORIGIN BREAKS
Expected: the missing musical resolution and the story event reinforce each other.

## Auditory vocabulary

Listen for these categories during normal play.

Observation
Expected: light, curious, unresolved.

Discovery / law
Expected: settled and conclusive.

World change
Expected: larger and lower, as if the field itself moved.

Ability / mode
Expected: brighter contour associated with the learned prime.

Bond
Expected: two sounds converging.

Key item
Expected: compact five note structural cue.

Anomaly
Expected: recognizably stranger and less resolved.

## Questions to answer at your first note

1. Did the added FOUR NOTES moment make Origin more emotionally meaningful?
2. Did it slow the opening too much?
3. Which event sound immediately felt right?
4. Which sound felt annoying, weak or too similar to another?
5. Did any event still play two competing success sounds?
6. Did you ever understand the category of an event from sound before reading it?
