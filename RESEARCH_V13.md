# PHASE v13 Research Note

## Topic
Event boundaries, attention, and memory.

## Research observations

1. People naturally segment continuous experience into meaningful events.
2. Perceptible event boundaries can improve memory for information associated with the boundary and help organize episodes.
3. Boundaries also consume attention while the current event model is updated. Recent work reports a cost for some information presented immediately after a boundary even while source or context memory improves.
4. Distinct boundaries can help separate meaningful emotional information that would otherwise blend into a continuous stream.

## Design interpretation for PHASE

A major game event should not be followed immediately by another explanation.

Use this rhythm:

change
silence
name the event
show its meaning
require deliberate acknowledgment
brief recovery
return control

Routine information should remain lightweight. Full event boundaries are reserved for changes to P, Origin, Phi, or the topology of the world.

## v13 changes

1. Remove the redundant Echo Reach story card that said the signal continued east.
2. Prevent held or repeatedly mashed confirm keys from dismissing major moments.
3. Stage story presentation so title and meaning do not appear simultaneously.
4. Stage acquisition presentation so the symbol arrives before explanatory copy.
5. Suppress transient chatter while a major moment owns attention.
6. Promote Origin restored and the Fivefold Gate opening into true event boundaries.
7. Separate a simultaneous ability acquisition from the subsequent world state story beat.
8. Add a short input recovery interval after a major moment closes.
