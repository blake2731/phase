# PHASE v11 Tester Reference

Play naturally once before using this sheet. Then use it for a deliberate completion pass.

## Core progression

1. ORIGIN LIGHTS
   Action: Wake the four home lights and return to Origin.
   Expected: Origin breaks and three notes scatter.

2. PATH NOTE ΔP
   Region: Origin.
   Action: Follow the illuminated steps.
   Reward: Field Journal.

3. PULSE NOTE 2
   Region: Origin.
   Action: Approach the pulsing ring.
   Reward: Prime Pulse, Mode 2.
   Expected starting Pulse radius: 240.

4. RESONANT REACH
   Region: Origin.
   Action: Pulse three small fieldlings with Mode 2.
   Reward: Pulse radius increases to 350.
   Purpose: This is the first proof that exploration changes P's capabilities.

5. TUNING NOTE 3
   Region: East side of Origin, inside the visible unstable hollow.
   Action: After Resonant Reach, stand at the hollow edge and pulse the triangular note.
   Reward: Mode 3.
   Important: The starting 240 radius should NOT be able to reach it. Radius 350 should.

6. COORDINATE BASIN
   Action: Activate resonators 2, 3 and 5.
   Reward: Mode 5, eastern boundary opens.

7. RESONANT SPAN
   Action: Hold Mode 3 and Mode 5 resonance at the same time.
   Reward: Bridge.

8. SYMMETRY GARDEN
   Action: Activate all five Mode 5 anchors while close enough.
   Reward: Restore Phi.

9. FIVEFOLD KEY
   Action: Return west with Phi to the object beyond P's field edge.
   Reward: Phi retrieves the key.

10. FIVEFOLD GATE
    Action: Return east. Phi installs the key.
    Reward: Passage opens.

11. SIGNAL RELAY
    Action: Follow the signal to the first apparent source.
    Expected: It is revealed as a relay, not the true source.

12. ECHO REACH
    Action: Continue east to the true source.

## Resonance progression thread

### Fieldlings
Trigger: Pulse three fieldlings near Origin.
Discovery: THE SMALL ONES COPY YOU
Formula: f_mote ← f_P
Reward: RESONANT REACH
Pulse radius: 240 → 350

### Octave
Region: Coordinate Basin.
Trigger: After solving the Mode 2 resonator, keep pulsing it until the octave discovery appears.
Formula: 2 → 4 → 8
Reward: OCTAVE REACH
Pulse radius: 350 → 420

### Superposition
Region: South of the Span approach.
Landmark: Large unstable circular pocket containing a distant 2/3 structure.
Requirement: Mode 3 plus enough Pulse range to cross the pocket.
Action: Hit the distant structure once with Mode 2 and once with Mode 3.
Formula: ∑
Reward: SUPERPOSITION REACH
Pulse radius: 420 → 490
Note: The old walk-over ∑ collectible is disabled in v11. This is its replacement.

### Common Field
Region: Deep Field.
Trigger: Activate the optional 2, 3 and 5 structure.
Formula: 2 · 3 · 5
Reward: COMMON REACH
Pulse radius: 490 → 570

### Harmonic Relay
Region: Echo Reach.
Trigger: Activate its optional 2, 3 and 5 relay nodes.
Formula: 2 : 3 : 5
Reward: HARMONIC REACH
Pulse radius: 570 → 660

### Returning Wave
Region: Echo Reach.
Trigger: Pulse the Echo Well and wait for it to return your mode.
Formula: f_out = f_in
Reward: ECHO PULSE
Effect: Player pulses automatically create a weaker second wave after a short delay.

## Things to deliberately test

### Pulse range readability
1. Pulse immediately after learning Mode 2.
2. Confirm the termination ring makes 240 feel visibly short.
3. Try to hit Mode 3 before Resonant Reach. It should fail.
4. Unlock Resonant Reach and try again. It should now succeed.
5. Try the Superposition structure before Octave Reach. It should fall short.
6. Unlock Octave Reach and confirm it becomes reachable.

### Backtracking memory
Notice objects that appear outside Pulse range before upgrades. Ask whether later range increases make you remember them naturally without a quest marker.

### Echo Pulse
After Returning Wave is discovered, emit one pulse in open space. A weaker second pulse should appear about 0.72 seconds later.

### Input safety
While moving, open the Journal, click outside the canvas, switch tabs, and return. P should never continue moving without fresh input.

### Story staging
Major story moments should stop play and wait for acknowledgment. Ordinary objectives should remain top right.
